## 🚀 Featured Project

### 🚕 RideFlow — Real-Time Ride Booking & Tracking Platform

Architected a full-stack real-time ride-hailing platform enabling live driver tracking and instant ride status synchronization.

**Highlights:**
- 📍 Live driver tracking & instant ride sync via Socket.io WebSockets + Leaflet Maps
- 🗄️ High-performance PostgreSQL schema (Prisma ORM) managing multi-role workflows — Riders, Drivers, Admins, wallets, fare calculation & surge pricing
- 🔒 End-to-end encrypted in-app messaging (AES-CBC) between riders and drivers
- 💳 Razorpay integration with a custom wallet system for real-time transactions & automated driver payouts
- 🔐 Role-based authorization (RBAC) + JWT securing driver, admin, and live-location endpoints

**Stack:** `Next.js 16` `Node.js` `Express` `PostgreSQL` `Prisma` `Socket.io` `Leaflet` `Razorpay` `Redis`
